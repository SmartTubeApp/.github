## 🧩 This is SmartTube

SmartTube is an Android TV media client.

It allows to browse media content with your own rules on Android TV.

## 🚀 Features

- Clean interface
- Designed for TV screens
- Up to 8K video resolution
- Login into your account
- Cast from the phone
- Support tv box remote controller
- Support external software keyboard
- Support devices without Google Services
